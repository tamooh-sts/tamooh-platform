# منصة طموح — المنصة التشغيلية والإدارية

مبادرة طموح (Tamooh by STS) · الجمعية السعودية للسياحة · جامعة الملك سعود

## محتويات المشروع

```
index.html            الواجهة والأقسام الخمسة
css/styles.css        التصميم
js/config.js          الإعدادات (مفاتيح Supabase، ملح التجزئة، رمز التفعيل الأول)
js/data.js            طبقة البيانات والهوية (تخزين محلي + Supabase)
js/app.js             منطق المنصة والصلاحيات
assets/               شعارات طموح والجمعية والجامعة
supabase/schema.sql   مخطط قاعدة البيانات ودوال الدخول الآمنة
```

## التشغيل الفوري (جهاز واحد)

افتح `index.html` من خادم محلي، أو ارفع المجلد إلى أي استضافة. بدون مفاتيح Supabase تعمل المنصة بالتخزين المحلي في المتصفح، وهذا الوضع مناسب للتجربة والإعداد فقط.

- **أول دخول:** بوابة العضو ← تفعيل الحساب لأول مرة ← اختر «عبدالإله سعود الهلقمي».
- **رمز التفعيل:** الرمز `TAMOOH-1448` (من `js/config.js`)، ثم أدخل الرقم الجامعي والهوية.

## الربط بقاعدة البيانات في 3 خطوات (للدخول من أي جهاز)

1. **أنشئ قاعدة البيانات.**
   - أنشئ مشروعاً مجانياً في supabase.com.
   - افتح `supabase/schema.sql` وغيّر `CHANGE-ME` إلى رمز سري بأحرف إنجليزية كبيرة، مثل `TAMOOH-7Q2K`.
   - الصق الملف كاملاً في SQL Editor ← Run.
2. **ضع المفاتيح.**
   - من Project Settings ← API انسخ `Project URL` و `anon public key`.
   - ضعهما في `js/config.js`.
   - غيّر `ID_SALT` إلى نص عشوائي طويل، ولا تغيّره بعد الإطلاق.
3. **انشر الموقع.**
   - ارفع المجلد كاملاً إلى GitHub Pages أو Netlify أو Vercel.
   - افتح الرابط، وسيُفعّل قائد المبادرة حسابه بالرمز الذي وضعته في الخطوة 1.
   - بعدها يصدر رموز التفعيل لبقية الإدارة العليا وقادة اللجان من «إدارة الأعضاء والحسابات».

> صفحة المعاينة على claude.ai تعمل بالتخزين المحلي فقط، لأنها لا تسمح بالاتصال بخوادم خارجية. للتشغيل الفعلي انشر المجلد على استضافتك.

## الصلاحيات

| الدور | الصلاحيات |
|---|---|
| الإدارة العليا (القائد، النائب، المساعدون) | كل اللجان، إسناد المهام لأي عضو، إصدار رموز التفعيل، تعديل الأعضاء ونقلهم، كل التقارير، كل طلبات التقديم وقبولها |
| قادة اللجان ونوابهم | أعضاء لجنتهم، إسناد مهام اللجنة واعتمادها، التقييم واعتماد الساعات والحضور، طلبات المتقدمين للجنتهم وقبولهم |
| لجنة الجودة والتطوير (القائدة والنائبة) | ما سبق، إضافة إلى عرض تقارير جميع الأعضاء وتقييمهم |
| العضو | صفحته ولجنته، مهامه وتحديثها، تقرير أدائه، طلب اعتماد الساعات، الفعاليات |

## حماية الهوية

- **التخزين:** لا يُحفظ رقم الهوية الوطنية في أي مكان. يُحفظ أثره المشفّر SHA-256 مع الملح فقط.
- **الحسابات:** جدولا `credentials` و `applicant_secrets` لا يُقرآن من المتصفح إطلاقاً. الدخول والتفعيل وإصدار الرموز والقبول تتم عبر دوال على الخادم تتحقق من صلاحية المنفّذ.
- **البيانات التشغيلية:** جدول `records` (المهام، الأعضاء، الطلبات…) مفتوح للقراءة والكتابة بالمفتاح العام. قيود الصلاحيات عليه تطبّقها الواجهة.
- **قبل حفظ بيانات حساسة على نطاق واسع:** يُنصح بإضافة Supabase Auth (رابط دخول عبر البريد الجامعي) وسياسات RLS لكل دور، كمرحلة ثانية.
